# 验收标准（MVP）：集装箱装箱优化器

## 1. 功能验收

### 1.1 输入
- 支持录入货物：L/W/H、重量、数量（必填）；可旋转、可堆叠/禁压、优先级（可选）
- 支持选择容器：标准库 + 自定义容器（内尺寸、载重上限）

### 1.2 求解
- 点击“求解”后返回方案：
  - placements：每件货物的容器编号、(x,y,z) 坐标、朝向（orientation）
  - score：至少包含体积装载率、剩余体积
  - warnings：若存在无法满足的约束或未装载项，必须明确列出原因
- 方案必须满足硬约束：不重叠、不越界、不超载（总重量不超过容器上限）

### 1.3 3D 展示
- 3D 视图支持：旋转、缩放、平移
- 支持选中高亮：在清单中点击某件货物后，3D 中高亮并聚焦（或明显可见）
- 支持显示装载率与关键指标（体积装载率、重量、剩余体积）

### 1.4 手动微调
- 支持拖拽移动与旋转（至少 90° 旋转；若支持任意角度需在 specs 定义）
- 微调后必须可执行校验：
  - 碰撞检测：与其他货物重叠时提示错误
  - 越界检测：超出容器边界提示错误
  - 超重检测：若手动导致超重（或分容器超重）提示错误
- 校验失败时：禁止导出“标记为有效的方案”（允许导出但必须标注 invalid）

### 1.5 导出
MVP 必须支持导出：
- plan.json：包含输入参数 + placements + score + warnings + 版本信息（算法版本/随机种子）
- items.csv 或 items.xlsx：装载清单（货物编号、箱号、坐标、朝向、尺寸、重量）
- view.png：3D 截图（至少 1 个视角）

## 2. 非功能验收

### 2.1 可复现
- 相同输入在相同版本下求解结果应可复现（若存在随机性，必须记录 seed 并可复现）

### 2.2 性能
- 在 20–200 件货物范围内求解时间满足团队约定阈值（在 `docs/specs/performance.md` 或本节补充具体数值）
- 3D 渲染在常见开发机上交互流畅（旋转/缩放无明显卡顿）

### 2.3 稳定性
- 导出文件内容与 UI 展示一致
- 异常输入必须有明确错误提示（缺字段、负数、尺寸为 0 等）

## 3. 验收用例（示例）
- 用例 A：规则箱体（20 件同规格纸箱）→ 高装载率，校验通过，可导出三件套
- 用例 B：混装（50 件多规格、部分不可旋转/禁压）→ 约束满足，warnings 为 0
- 用例 C：超载输入 → 求解返回 warnings/未装载项，且 UI 明确提示
